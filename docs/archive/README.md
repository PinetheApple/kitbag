# Archive

Historical documents, kept for the record and not maintained. The phase
trackers, the #33 device-gate runbook, the Wave 0 design inventory, the
time-signature research behind D1 and the note on the staged `config/` lint
setup describe the repo as it was when they were written; none of them is a
current plan, status or spec. SPEC.md is the source of truth, GitHub issues are
the tickets, and `docs/decisions.md` records why things were decided.
