# #574 queue: owner decisions (2026-11-20)

1. One queue shared by single songs and stem songs.
2. Queue entry points: a Queue key on the mini-player, a Queue icon on the stem player, and a Queue icon with a count on the Stem songs list.
3. "Next from: <setlist>" shows only for a setlist started in this listening session. Starting a song from a list ends it; starting a new setlist replaces it. Queued songs stay either way. "Clear queue" removes queued songs; "Leave setlist" removes the setlist part. Playback stops at the end, with no autoplay.
4. Repeat is a labelled chip cycling Off → Repeat all → Repeat one. Repeat all loops the queue and the setlist; an active A-B loop wins over Repeat one.
5. Previous and Next sit beside the Up next row. Past 3 s, Previous restarts a stem song; on the Metronome it always goes back an entry.
